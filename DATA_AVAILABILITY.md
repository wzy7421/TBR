# Data Availability Statement — release wording

Use the following wording **only after the real de-identified source data have been deposited and checked**:

> The de-identified data, experimental materials, codebook, and analysis-supporting files that support the findings of this study are openly available in [REPOSITORY NAME] at [PERSISTENT DOI OR URL].

If ethics/consent permits release of derived but not raw participant-level records, use wording that precisely states what is public and what is restricted. Do not describe template files, synthetic data, or reconstructed observations as empirical study data.

For archival citation, the preferred workflow is to create a tagged GitHub release and archive it in a recognized repository such as Zenodo or OSF, then replace the placeholder above with the persistent DOI/URL.
